# storybyvote

Daily episodes of the interactive cartoon series "Last Guy Awake" for TikTok @storybyvote.
Viewers vote in a comment poll, the winner decides the next episode.

- `bible.json`: story bible (characters, episodes, poll results, open threads)
- `pipeline/`: Pillow renderer, captions aligned with pocketsphinx, synthesized sound, `build.sh` to build one episode
- `pipeline/episodes/`: script and scene file of every episode
- branch `uploads`: only the current video, used as the public URL for Buffer

Font: Poppins (SIL Open Font License). Voice: ElevenLabs (paid plan, commercial use allowed). All drawings and sounds are generated by code.
See `CLAUDE.md` for the daily workflow.
